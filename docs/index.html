Security & Architecture

Secure, local and offline

Your data stays on your machine — no external network requests are ever made.

🔒

Isolated Renderer

contextIsolation and sandbox enabled, with nodeIntegration disabled.

🚫

External Network Blocked

All traffic is restricted to 127.0.0.1 — nothing leaves your device.

🗄️

Portable Database

An embedded PostgreSQL that provisions itself and runs fully self-contained.
