Features

كل ما يحتاجه متجرك في تطبيق واحد

من استقبال الجهاز للصيانة حتى بيع الهاتف بالتقسيط — كل شيء في نظام واحد منسّق.

📦

إدارة المخزون

هواتف وملحقات مع الماركة والطراز واللون والسعة والـ IMEI، مع تنبيهات الحد الأدنى للمخزون.

🧾

نقطة البيع (كاشير)

فواتير سريعة، خصومات، طرق دفع متعددة، وطباعة إيصالات احترافية.

🔧

إدارة التصليحات

تذاكر صيانة، تشخيص الأعطال، قطع الغيار، تعيين الفني وتتبّع حالة الجهاز.

📅

نظام التقسيط

الدفعة الأولى، جدول الأقساط الشهرية، الأقساط المتبقية ومواعيد الاستحقاق.

🛒

المشتريات والموردون

تسجيل فواتير الشراء وإعادة تعبئة المخزون بضغطة واحدة.

💸

المصروفات

تصنيف مصروفات المحل ومتابعتها بدقة مع طرق الدفع.

📈

تحليل الأرباح

حساب الربح من التكلفة مقابل سعر البيع وتقارير ربحية واضحة.

📊

تقارير وتصدير Excel

تقارير تفصيلية قابلة للتصدير إلى ملفات Excel بضغطة زر.

👷

العاملون والصلاحيات

أدوار، رواتب، ودخول محمي بـ PIN مع صلاحيات لكل صفحة.

⚙️

إعدادات المحل

الاسم، الشعار، العملة، الضريبة، وتذييل الإيصال — كل شيء قابل للتخصيص.

🛡️

النسخ الاحتياطي

نسخ واسترجاع آمن لقاعدة البيانات لحماية بياناتك.

🌙

وضع ليلي + ثنائي اللغة

واجهة عربية/إنجليزية كاملة مع دعم RTL ووضع ليلي مريح للعين.

Security & Architecture
